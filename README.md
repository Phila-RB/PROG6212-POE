cd YOUR-REPOSITORY

If you're using Visual Studio, open the .sln file or the .csproj file from the cloned folder.

In the repository folder, run:
bash
dotnet restore

dotnet build

dotnet run

Open the Swagger URL shown in your terminal, usually something like:

https://localhost:7004/swagger

Roles:

Participant - can join events

Organiser - can create events
